# harry-potter-shop

학습용 해리 포터 상점입니다. 공식 판매처가 아닙니다.

- `client` — Vite + React
- `server` — Express + MongoDB

## 시작하기

```bash
cd server
cp .env.example .env
npm install
npm run dev
```

```bash
cd client
cp .env.example .env
npm install
npm run dev
```

- 상점: http://localhost:5173
- API: http://localhost:4000

`MONGODB_ATLAS_URL`이 있으면 Atlas에 연결하고, 없으면 로컬 MongoDB를 사용합니다.
